# MM OVERSEAS

Premium static corporate website for MM OVERSEAS — edible oil manufacturing, oilseed processing and procurement.

## Stack

- React
- Vite
- Tailwind CSS v4
- React Router

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Replace later

- Contact address, phone, email and Google Maps embed in `src/pages/Contact.jsx`
- FSSAI license number in `src/pages/Procurement.jsx`
- Plant photographs in `src/pages/About.jsx` gallery
